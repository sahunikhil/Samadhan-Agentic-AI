# Order Changes and Cancellations

## Cancelling an order

You can cancel an order **free of charge while its status is `processing`** (before it ships). Cancellation is instant and the payment authorization hold is released within 3-5 business days.

Once an order has shipped it can no longer be cancelled. Instead, you can refuse the delivery or return it after it arrives under our *Returns and Refunds Policy*.

## Changing the shipping address

The shipping address can be changed only while the order is `processing`. After shipping, use the carrier's redirect options (UPS My Choice, FedEx Delivery Manager) from the tracking page. Redirects to a different city may add carrier fees.

## Changing items

We cannot add or remove items from an order that has already been placed. Cancel the order while it is processing and place a new one, or place a separate order for additional items.

## Order statuses explained

| Status | Meaning |
| --- | --- |
| processing | Payment authorized, preparing to ship. Changes and cancellation allowed. |
| shipped | Handed to the carrier. Tracking available. |
| in_transit | Moving through the carrier network. |
| out_for_delivery | On the truck for delivery today. |
| delivered | Delivered to the address or pickup point. Return window starts. |
| cancelled | Cancelled before shipping. No charge. |
| return_requested | A return (RMA) has been created. |
| refunded | The refund has been issued. |
